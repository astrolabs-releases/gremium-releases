# gremium

Downloads for the gremium desktop app. The source code is private; this
repository only hosts the installers.

## Download

Get the latest version from the
[Releases page](https://github.com/astrolabs-releases/gremium-releases/releases/latest).

| Platform | File |
| --- | --- |
| macOS (Apple Silicon) | `gremium_<version>_aarch64.dmg` |
| macOS (Intel) | `gremium_<version>_x64.dmg` |
| Windows | `gremium_<version>_x64-setup.exe` or `.msi` |
| Linux | `.AppImage`, `.deb` (Debian/Ubuntu) or `.rpm` (Fedora/RHEL) |
